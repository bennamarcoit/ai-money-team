# 01 – Team Operativo

**Accesso limitato per agente.**

Ogni agente specializzato deve leggere **solo** la propria sottocartella.
Non cercare in altre cartelle del team.

| Agente              | Cartella dedicata          |
|---------------------|----------------------------|
| Researcher          | `researcher/`              |
| Idea Generator      | `idea-generator/`          |
| Critic              | `critic/`                  |
| Response Analyst    | `response-analyst/`        |
| Planner             | `planner/`                 |
| Writer              | `writer/`                  |
| Resource Scout      | `resource-scout/`          |
| Builder             | `builder/`                 |

Il Board ha accesso a tutto.
