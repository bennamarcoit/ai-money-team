# Regola globale: Niente si perde

**Fonte unica di verità:**
- Prompt, regole, checklist, risorse → GitHub (`ai-money-team`)
- Decisioni, risultati, limiti, piani, output → Notion (pagina Centro di Comando + database)

## Obblighi
1. Ogni decisione importante del Board va scritta su Notion.
2. Ogni risorsa nuova trovata dal Resource Scout va aggiunta su GitHub nella cartella corretta.
3. Ogni output utile del team va salvato su Notion.
4. Nessun agente può considerare un lavoro finito se non è stato salvato.
5. Se qualcosa non è su Notion o GitHub, non esiste.

Questa regola vale per tutti gli agenti.
