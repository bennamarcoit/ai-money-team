# Checklist Qualità – Sito / Landing

Prima di approvare un sito o una landing:

- [ ] Deploy su Vercel / Netlify (o equivalente)
- [ ] Dominio collegato (se previsto)
- [ ] Google Analytics 4 (o Plausible)
- [ ] Microsoft Clarity (o Hotjar)
- [ ] Meta Pixel / TikTok Pixel (se ads)
- [ ] Meta title, description, Open Graph
- [ ] Favicon e immagini ottimizzate
- [ ] Mobile responsive
- [ ] Velocità base (Lighthouse > 80)
- [ ] Privacy / Cookie banner (se necessario)
- [ ] Link e form funzionanti
- [ ] CTA chiare

**Note:** Aggiungi qui qualsiasi altro criterio specifico del progetto.
